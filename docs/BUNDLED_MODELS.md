# 随附模型与校准数据

下载[2026-10-27 P01模型与校准数据包](https://github.com/Jameszfyj/eeg-acquisition-decoding/releases/tag/p01-bundle-20261027)中的 `p01-models-and-calibration-20261027.zip`，将内容解压到本项目根目录。

如果已有自己的 `configs/subject_models.json` 或 `configs/workbench.local.json`，先保留副本，再合并模型条目和本机设置。解压不会启动硬件。

## 启动

1. 按首页建立Python环境，安装 `pip install -e ".[decode,studio-v2]"`。
2. 解压数据包到项目根目录，双击 `启动解码.cmd`。
3. 打开 `http://127.0.0.1:57475/`，默认模型应为 **P01 · 六类v2 · 20轮专用校准**。页面左侧可打开57500端口的MI Studio v2工具。

默认模型已拟合专用校准头，可直接执行模型检查。实体设备解码仍需选择当前脑电设备、核对通道并开始；打开网页不会自动连接或驱动机械手。

| `runtime/continuous/20261027_203237_19b894b4_P01/` | 19:52原始采集会话的校准导入记录，120次、每类20次，含完整 `source/session.json`、`source/data.h5` 和提取后的原始校准数组 |

## 使用校准数据

通用模型或上一版双IFNet模型可在平台选择兼容的“已保存校准”。也可在“导入外部校准数据”中选择上述记录内的 `source/` 文件夹。

**v2须使用MI Studio v2校准工具**。在工具中选择完整 `source/` 文件夹，并选择 `models/p01/v2/source.pt`；按任务名称确认类别映射，生成后导入新的 `calibrated.pt`。只包含想象阶段的NPZ缺少v2所需的准备前历史，不能代替原始会话。

原采集类别顺序为：左握拳、右握拳、左旋臂、右旋臂、舌头、双脚。v2输出顺序为：左旋臂、左握拳、右握拳、右旋臂、双脚、舌头。包中已校准模型按这个对应关系拟合，手势依次为拇指、食指、无名指、小指、OK、中指。

准备时长不必固定，数据提取按实际事件采样索引；这两份记录是准备约2.5秒、想象4秒。20轮指六类各20次，共120次任务。

## 验证范围

这是P01的研究模型和既有记录，不应当作其他被试或重新戴帽后的通用校准。保留原始 `training_compatible=false` 及 `device_event_time_semantics_unverified` 标记；物理提示起点尚未独立测量。

v2源PT与ONNX输出已核对，专用校准、导出和平台接口已检查；实体设备上的新一轮在线效果尚未验证。校准内部诊断分数不等于独立在线准确率。

仓库中的MI Studio v2支持源模型载入、冻结骨干校准、ONNX导出与部署推理，所需网络结构随代码提供。完整的源模型重新训练仍依赖原cargame训练环境；该功能未作为本次可移植流程的一部分验证。
