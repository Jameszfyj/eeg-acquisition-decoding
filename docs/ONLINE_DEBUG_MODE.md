# 在线调试模式

当前 `handbci.continuous_online.ONLINE_CALIBRATION_ENABLED = False`。这是统一的临时后端策略，页面请求不能开启校准。恢复功能时需修改此开关并重启后端。

所有在线模型可直接进入连接测试、自由解码和带提示采集。`/api/calibration/start` 及其他开始接口中 `session_purpose=calibration` 的请求均拒绝。页面隐藏脑电校准段、历史校准数据入口及专用校准工具入口。旧页面传来的“重新校准”或“复用历史原始脑电”选项被忽略，因为复用原始脑电也会重新拟合参数。

已有模型参数保持不变：ONNX 的内置校准、模型绑定的独立参数文件、v2 文件中的校准输出头仍用于推理。不会修改模型文件，不会为本次调试会话生成可复用的“已完成校准”记录。

没有校准参数时：

- 普通 ONNX/PT 使用模型原有输出，不增加在线偏置或收集校准试次。
- 改进六分类和重训双 IFNet 保留原有预处理与脚舌路由；无 EA 参数时不做对齐变换，无现场偏置时不应用该修正。
- 右手专项模型缺少现场校准阈值时跳过附加复判，保留基础/脚舌解码；推理记录写明跳过原因。
- v2 源模型使用原有输出头；存在校准头时保留该头。

会话配置、模型选择及相应推理记录标明 `online_calibration_disabled`；未校准输出不标为已完成校准。离线录制、离线 ONNX 验证和机械手姿态配置不受这一策略影响。独立的训练/校准算法仍保留供后续恢复使用。

## 断开连接

在线工作台的脑电连接设置中提供“断开连接”，对应带页面令牌验证的 `POST /api/disconnect`。

按钮可在采集、校准检验、连接检验或空闲时使用。请求立即返回，界面显示“正在断开”；采集线程仍负责写入尾部数据、封存记录、关闭 TriggerBox/脑电连接以及释放连接占用。正在执行的机械手动作会收到取消请求，并等待驱动关闭串口。原模型、界面参数和记录目录保留。

只有采集线程、连接检验、设备搜索和独立机械手任务都结束后，才显示“设备已断开”。断开过程中禁止新的连接、测试或开始请求；重复点击不跳过等待，也不强行终止保存。完成后可再次开始。此按钮保留网页服务；“关闭程序”则另行退出后端。

## 软件打标

带提示采集选择“软件标记 · 指令发出时记录”后，无需 TriggerBox、串口、无线事件接收或回传自检。切换模型不会覆盖用户选择的标记方式，旧硬件字段不参与软件模式连接。

软件事件在后端发出指令时同步记录主机单调时钟与墙钟，不进入硬件标记线程，也不等待回传。`marker_time_source=host_command_issue`，`echo_verified=false`；通过最小已观察到达偏移建立主机到设备采样时钟映射，估计指令发出时的对应源样点；连续迟到包不把标记拖回过去。会话封存时写入事件表和 H5 `trigger`，源样点落在丢包缺口时标为 `source_index_gap`，不移到后续样点。软件标记不等同于已测量的屏幕、音频或硬件物理呈现时间。硬件模式仍要求真实回传，不自动降级为软件标记。
