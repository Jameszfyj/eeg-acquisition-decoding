# P01 · 909次训练＋20轮校准 ONNX

下载[可直接导入的平台模型包](https://github.com/Jameszfyj/eeg-acquisition-decoding/releases/tag/p01-909-20round-onnx-20261028)中的 `P01_909_20round_calibrated_ONNX.zip`，约7.9MB。

使用支持 `handbci.retrained_six_onnx.v1` 的当前仓库版本。在解码平台展开“导入自己的模型”，被试编号填 **P01**，选择ZIP并导入。不要先解压；导入后选择 **P01 · 909次训练＋20轮校准 · 完整ONNX**。

模型已包含配套20轮、120次任务拟合出的校准结果，平台检查通过后可直接选择设备开始解码，不需要再传原始校准数据或单独的NPZ，也不会重复叠加通用校准。打开页面和导入模型不连接硬件。

这是原P01校准状态的完整部署包；其他人可以导入和运行，但换被试或重新戴帽后，不能把原参数当作新状态的校准。模型实际识别效果仍需单独验证。

## 导出内容

ZIP根目录仅包含 `manifest.json` 与单文件 `model.onnx`，无外部权重、Python代码、原始脑电或运行环境。全部模型及校准计算已写进ONNX，运行不依赖原训练目录或PT文件。

原模型909次任务、2727个训练窗，校准20轮、120次任务。实际采用的校准方法为 `ea_only`，来源为2026-10-27 20:28会话。EA矩阵随图保存，模型、参数来源和矩阵校验值在清单及图元数据中对应核对。

| 项目 | 约定 |
| --- | --- |
| 设备 | Neusen ACP，1000Hz、uV，32路设备通道按名称对齐 |
| 平台预处理 | 原201系数因果FIR、1000→250Hz、启动剔除1秒 |
| ONNX输入 | float32 `[1,30,700]`，250Hz FIR输出的最近2.8秒，模型通道顺序见清单 |
| 图内处理 | 原三个2秒窗口，0/0.4/0.8秒起始，窗内50Hz陷波、两套双频带、EA校准、双IFNet、三窗概率平均及脚舌分流 |
| ONNX输出 | float32 `[1,6]`概率，不需再次softmax |
| 类别顺序 | 左握拳、右握拳、左旋臂、右旋臂、双脚、舌头 |
| 对应手势 | 食指、无名指、拇指、小指、OK、中指 |

完整图包含固定500采样点滤波算子；输入长度固定为700，不能更改为普通单个2秒窗。因果FIR由平台执行；不要将原始1000Hz脑电直接送进ONNX。双向窗内滤波只使用已经到达的窗口数据，不需要未来流数据。

## 核对结果

使用18个人工信号、120次实际校准任务及489次历史在线预测进行导出前后比较，共627次；类别判断全部一致，概率最大绝对差约`2.21e-6`，样本时序和窗口边界一致。本机推理中位约5.5ms，仅为该电脑的接口核对结果，不代表其他电脑速度或实机识别准确率。
