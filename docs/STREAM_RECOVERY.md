# 实时预测与接收恢复

## 默认设置

实时工作台默认每0.1秒（10 Hz）更新预测，适用于已接入的ONNX、MI Studio v2及原生PT模型。模型输入窗口、通道、参考、单位、采样率、预处理和权重按各模型约定保留。独立使用模型库时的输入配置与工作台在线调度分别记录，见[模型接入](MODEL_IMPORT.md)。

除仅显示的四分类入口外，默认使用投票判决：2秒滚动窗口、65%得票、3.5秒最长等待、4秒动作间隔。每个概率向量的最高概率类别获得一票；不能把它理解为概率累加。页面中显式选择的判决模式和参数优先。

## 暂停与恢复

- 超过1秒未收到有效脑电：保留设备连接，暂停新动作并清空投票，显示“脑电暂缓”。
- 收到积压数据：原始有效数据照常归档，积压期间不推理、不驱动机械手。
- 接收恢复且积压排空：重置滤波与解码状态，重新积累完整窗口后才允许判决。
- 提示任务受到影响：保留中断尝试，恢复后为同一目标分配新的试次ID、显示回执及prepare/cue标记。已经执行的动作不会再次下发。

## CRC与停止条件

重复半包只有在逐字节前缀相同、后续完整包CRC和帧尾均独立通过时才被识别为`duplicate_prefix`，原始字节及完整包证据保留。不会拼接坏包或修改载荷。

可核验的孤立CRC故障按原始设备时间隔离，重建窗口；缺失样点保留为缺口，不插值或补点。带提示任务保留中断尝试后重新提示。

持续4秒无有效脑电、底层关闭或持续stalled、60秒内3次真实CRC、坏包边界无法确认、设备时间异常、队列溢出及写盘失败等情况仍停止并保存证据。此机制处理短时传输暂停，不能保证物理链路永不断流。

## 验证范围

自动测试使用合成信号、模拟串口和本机TCP，覆盖0.1秒窗口节奏、短暂停收恢复、真实长断流停止、CRC隔离、积压归档、重试试次和执行中的动作不重发。离线回放及关节位置读取只能分别证明历史算法行为与驱动反馈，不能代替整轮实时脑电控制验证。
